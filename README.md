# codex-ter-ui

Red pixel-banner theme for Termux: black background, red accents, custom prompt, extra-keys row, Nerd Font.

## Install

```bash
pkg install curl -y && curl -fsSL https://raw.githubusercontent.com/fozo-code/codex-ter-ui/main/install.sh | bash
```

Close Termux fully and reopen it.

## Commands

```bash
codex-ter-ui update      # update the theme
codex-ter-ui uninstall   # restore your old settings
codex-ter-ui banner      # show the banner again
```

Your previous `colors.properties`, `termux.properties` and `font.ttf` are backed up and restored on uninstall.
